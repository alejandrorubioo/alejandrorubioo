# Alejandro Rubio

Automation and robotics engineer. I work with industrial control systems, robots and the software around them.

## Projects

Most are university projects, many of them team work; each README states the team and the limits of what is published.

### Automation

- [OP10 robot cell](https://github.com/alejandrorubioo/op10-codesys-simumatik-robot-cell): virtual commissioning of a station with a CODESYS PLC, a Simumatik digital twin over OPC UA and an ABB robot.
- [MR Training Framework](https://github.com/alejandrorubioo/MR_Training_Framework_ASSAR): Unity mixed-reality training framework, built at the ASSAR Industrial Innovation Arena, connected to a PLC and an ABB robot controller.

### Robotics

- [Dual IRB120 coordination](https://github.com/alejandrorubioo/robotstudio-dual-irb120-coordination): two ABB IRB120 robots coordinated through I/O handshakes in RobotStudio and RAPID.
- [MultiMove welding cell](https://github.com/alejandrorubioo/abb-multimove-welding-cell): offline-programmed ABB MultiMove welding cell in RobotStudio.
- [Multi-robot ROS and Webots](https://github.com/alejandrorubioo/multirobot-ros-webots): ROS 1 TurtleBot fleets in Gazebo and a Webots Zumo swarm in C++.
- [TicTacToe with ABB](https://github.com/alejandrorubioo/TicTacToe-with-ABB): tic-tac-toe played by an ABB IRB 120 in RobotStudio, with a Python web app and RAPID modules.
- [Pololu Sumo (Webots)](https://github.com/alejandrorubioo/Pololu_Sumo_Multirrobot): simulated Pololu Zumo-style sumo robot with a C++ controller.
- [Camera Calibration](https://github.com/alejandrorubioo/Camera_Calibration): chessboard and circle-grid calibration with OpenCV, and a 3D car drawn over a webcam image.

### Mixed reality

- [AGV Path Planning](https://github.com/alejandrorubioo/AGV_PathPlanning_Final_MR): A* path planning for an AGV, set up with hand gestures in Unity (bachelor thesis).

### AI

- [Hate-speech classifiers](https://github.com/alejandrorubioo/hate-speech-classifiers): Naive Bayes, Gradient Boosting, XGBoost and TabNet compared on a hate-speech dataset.

## Skills

Unity and C#, Python, ABB RAPID and RobotStudio, CODESYS and IEC 61131-3, ROS and Gazebo, Webots, scikit-learn.
